# Редакция v2: один промпт на сеть каналов + двойная проверка GPT и Claude

## Как работает

1. Сборщик находит новость. До подготовки медиа и вызова нейросетей идёт дешёвая проверка на дубль недавно опубликованного поста: явный повтор сразу уходит в «Дубль сюжета» без расходов на медиа и редакцию. Затем готовится медиа (как раньше).
2. **Автор** (OpenAI, `OPENAI_MODEL`) получает системный промпт из `prompts/chto-tam.md`: общие правила и профиль только этого канала. Автор может пропустить новость (`status: skip`): низкая важность, старая, дубль в сети, реклама, запрет по закону. Пропущенная новость сохраняется со статусом `editorial_skip`.
3. **Проверка**: тот же промпт в роли `checker` уходит параллельно в OpenAI и в Anthropic Claude (`ANTHROPIC_MODEL`). Каждый сверяет цифры, даты и имена с источниками, юридические пометки и запреты профиля. Побеждает самый строгий вердикт.
4. `fix` — пост уходит автору с замечаниями (`fix_notes`), не больше `EDITORIAL_V2_MAX_FIX_ROUNDS` раз.
5. Итог:
   - `pass` — пост в очереди с `qcStatus: pass`, его возьмёт расписание;
   - `reject`, ошибки после всех исправлений, дословное совпадение с источником или недоступна одна из нейросетей — пост в очереди с `qcStatus: hold`. Сам он не опубликуется, причина видна в карточке.
6. Склейка нескольких источников в одну историю идёт через тот же цикл «автор + две проверки» (`merge_check`).

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `EDITORIAL_V2_ENABLED` | `true` | `false` — мгновенный откат на старую схему рерайт + QC |
| `ANTHROPIC_API_KEY` | — | ключ Claude; без него проверяет только GPT |
| `ANTHROPIC_MODEL` | `claude-sonnet-5-5` | модель Claude для проверки |
| `EDITORIAL_V2_MAX_FIX_ROUNDS` | `2` | сколько раз автор может исправлять пост |
| `EDITORIAL_V2_REQUIRE_ALL_CHECKERS` | `true` | если одна из нейросетей не ответила, пост ждёт ручной проверки |
| `STORY_PRECHECK_ENABLED` | `true` | проверка на дубль до медиа и нейросетей; `false` — только после написания поста |
| `SCHEDULER_SLOT_WINDOW_MINUTES` | `10` | окно, в течение которого слот расписания ещё можно выполнить |

## Каналы

Профиль канала определяется полем `channelId` кабинета. Для `ai-main` это `ai`, для `chtotamtachki` — `auto`; для остальных профиль угадывается по названию. Явно задать профиль:

```
POST /api/workspaces/update  {"id": "<кабинет>", "channelId": "crypto"}
```

Допустимые значения: `ai auto money tech games kino science sport world stars travel shopping home food business crypto`.

## Реестр иноагентов и запрещённых организаций

```
GET  /api/editorial/registry
POST /api/editorial/registry  {"foreign_agents": ["…"], "banned_orgs": ["…"]}
```

Хранится в `/data/editorial-registry.json`. В модель уходят только те имена, которые встречаются в тексте источников.

## Диагностика

- `GET /api/editorial/status` — включена ли редакция, какие нейросети проверяют, последние вердикты.
- Админка → «Подключения» → «Редакция v2 (GPT + Claude)».
- В карточке новости: `editorialV2` — вердикт, раунды исправлений, ответ каждой нейросети, ошибки.
